# GLOSARIO

| Término | Definición en este proyecto |
|---|---|
| Bake-off | Cocción/terminación en el punto de venta de productos elaborados previamente (en general congelados). |
| Producción centralizada | Elaboración en una planta central (propia o de terceros) que abastece a los locales. |
| Ultracongelado | Producto congelado rápidamente a muy baja temperatura para preservar estructura y calidad. |
| Pre-fermentado / pre-cocido | Estados intermedios del producto congelado que cambian el trabajo necesario en local. |
| SKU | Unidad de producto distinta en el menú/inventario. |
| Food cost | Costo de materia prima / precio de venta neto. |
| Ticket promedio | Venta total / cantidad de tickets. |
| UPT | Unidades por ticket. |
| Break-even | Nivel de ventas en el que el resultado operativo es cero. |
| Payback | Tiempo en recuperar la inversión inicial con el flujo generado. |
| EBITDA | Resultado antes de intereses, impuestos, depreciaciones y amortizaciones. |
| CAPEX / OPEX | Inversión inicial / gastos operativos recurrentes. |
| TAM / SAM / SOM | Mercado total / mercado accesible / mercado capturable estimado. |
| Gate | Punto de control donde se decide si avanzar (GO), avanzar con condiciones, reciclar o frenar. |
| SOP | Procedimiento operativo estándar (formato apto para manual de franquicia). |
| Microzona | Área de influencia peatonal de un local (típicamente pocas cuadras). |
| Kill criteria | Condiciones predefinidas que, si se cumplen, implican abandonar una opción. |
| CCT | Convenio colectivo de trabajo aplicable. |
| BPM / HACCP | Buenas prácticas de manufactura / análisis de peligros y puntos críticos de control. |
