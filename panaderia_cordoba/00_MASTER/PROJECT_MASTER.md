# PROJECT MASTER — Proyecto Panadería Córdoba (PAN-CBA)

> Mapa principal del proyecto. Debe poder leerse en 2–3 minutos. Detalle → documentos enlazados.
> Última actualización: 2026-09-24

## 1. Objetivo
- **Corto plazo:** diseñar, desarrollar, abrir y validar una primera panadería en Córdoba Capital, Argentina.
- **Largo plazo:** convertir el modelo validado en un sistema estandarizado, replicable y potencialmente franquiciable.

## 2. Visión
No abrir "una panadería que funciona", sino construir: **modelo de negocio probado + marca + sistema operativo + números validados + manuales + procesos + tecnología + indicadores + documentación suficiente para replicar.**
El primer local es simultáneamente: **negocio + laboratorio + unidad piloto + base del futuro modelo de franquicia.**

## 3. Criterios de diseño del negocio (filtro para toda decisión)
Rentable · diferenciable · escalable · estandarizable · fácil de operar · medible · documentable · replicable · controlable · franquiciable.
Doble perspectiva obligatoria: **(1) primera unidad** / **(2) red de 5–100 locales**.

## 4. Alcance
Mercado, competencia, cliente, concepto, producto, pricing, modelo financiero, ubicación, operaciones, layout/equipamiento, RRHH, experiencia de cliente, tecnología, marketing, legal, apertura, KPIs y preparación para franquicia. Ver `ROADMAP.md`.

## 6. Contexto estratégico clave
- Existe la posibilidad de vincularse con **una empresa que fabrica panificados congelados** → habilita modelos de producción centralizada / bake-off en punto de venta. **No se asume que centralizar sea lo mejor**: se evaluará económica y operativamente (I010–I012, Q011–Q014).
- Identidad y condiciones de esa vinculación aún no documentadas (Q040).
