# REGISTRO DE DECISIONES

> Sólo se registran como `D###` las decisiones **aprobadas por los socios**. Las recomendaciones de la IA no son decisiones.
> Las decisiones por tomar se listan como `PD###` (pendientes). Al aprobarse, se crea el D### y la PD se cierra con referencia.

## Decisiones aprobadas
_Ninguna todavía._

### Formato de registro
```
### D### — [Título corto]
- Fecha:
- Tipo: Estratégica / Táctica / Operativa
- Gate:
- Decisión requerida:
- Contexto:
- Alternativas consideradas:
- Datos utilizados: (I###, F###, A###)
- Decisión tomada:
- Motivos:
- Impacto (local 1 / red):
- Riesgos: (R###)
- Responsable:
- Aprobada por:
- Fecha de revisión:
- Reemplaza a / Reemplazada por:
- Origen: PD###
```
