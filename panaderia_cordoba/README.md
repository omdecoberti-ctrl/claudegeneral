# Proyecto Panadería Córdoba (PAN-CBA)

Fuente única de verdad del proyecto para diseñar, abrir y validar una primera panadería en Córdoba Capital y convertirla en un modelo replicable y potencialmente franquiciable.

**Empezar por:** `00_MASTER/PROJECT_MASTER.md` → `00_MASTER/STATUS.md` → `00_MASTER/ROADMAP.md`.
**Reglas para la IA / colaboradores:** `CLAUDE.md` y `00_MASTER/METHODOLOGY.md`.

## Estructura

  GATE_REVIEWS/             Actas de cierre de cada Gate
